> **Celebration Canvas** is a rich visual graphic workspace and greeting customization engine built with **React**, **Shadcn UI**, **Radix primitives**, and **Recharts**. It allows users to design, customize, and export personalized greeting cards and celebration collateral.

---

## ✨ Features

- 📐 **Modular Design Canvas:** Resizable panels (`react-resizable-panels`) with drag-and-drop customization controls.
- 🎨 **Shadcn UI Component Architecture:** Full suite of accessible Radix UI primitives with smooth Tailwind transitions.
- 📊 **Real-Time Visual Feedback:** Form state management with `react-hook-form` and `zod` runtime schema validation.

---

## 🚀 Quick Start
```bash
git clone https://github.com/sangamesh5588/celebration-canvas.git
cd celebration-canvas
npm install
npm run dev
```
